# Entity Framework Core Migrations

To create and apply migrations, run the following commands in the project directory:

```bash
dotnet ef migrations add InitialCreate
dotnet ef database update
```

This will create the database schema with tables for:
- Countries
- Customers
- Hotels
- Orders

With appropriate relationships and constraints as defined in the models.

Note: The actual migration files will be generated by the EF Core tools and placed in this directory.
