# Bootstrap

This directory contains Bootstrap 5.2.3 library files for the application.

Bootstrap is a popular front-end framework for building responsive, mobile-first websites. This application uses Bootstrap for its UI components, grid system, and responsive design features.

## Directory Structure
- `/css` - Contains Bootstrap CSS files
- `/js` - Contains Bootstrap JavaScript files

## Version
Bootstrap 5.2.3
