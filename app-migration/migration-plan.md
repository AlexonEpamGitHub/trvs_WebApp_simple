# .NET Migration Plan

## Overview
This document outlines the plan for migrating the WebApplication452_simple project from .NET Framework 4.5.2 to .NET Core 8.

## Migration Steps
1. Create a new .NET Core 8 project structure
2. Migrate models and DB context to Entity Framework Core
3. Update controllers to use ASP.NET Core patterns
4. Migrate views to Razor Pages compatible format
5. Update configuration and dependency injection
6. Update front-end assets (Bootstrap, jQuery)
7. Test and refine
